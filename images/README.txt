Put your photos and paper thumbnails here.

You don't edit any HTML. Reference an image from content.json.

Current files:
  - portrait.jpg           your hero photo (front page only). Shown large and
                           rectangular; any size works. Set via profile.portrait.
  - favicon.png            browser-tab icon (256x256 square).
  - apple-touch-icon.png   phone home-screen icon (180x180 square).

Optional, when you add them:
  - <paper>_thumb.png      small "journal icon" next to a paper. Reference it
                           with  "thumb": "images/<paper>_thumb.png"  on that
                           paper in content.json. No thumb = a tidy PDF box.

See ../README.md for the full editing guide (incl. how to make a favicon
or a thumbnail with one `sips` command).
